保护上次成功同步的数据，不是实时 RAID。

磁盘与角色

Content 副本至少为校验级别 + 1，分布在独立磁盘。默认在所有选中盘上保留。

仅生成配置，不格式化磁盘，不自动开始首次同步。首次同步完成前数据未建立校验保护。
