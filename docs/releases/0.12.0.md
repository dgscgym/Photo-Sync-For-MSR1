# v0.12.0 · Android 首个可调试版本

新增原生 Android 客户端（Android 8+），已接入真实服务端接口：客户端账户和 TOTP/恢复码、Keystore 加密会话、照片/视频浏览、详细元数据、Live 双资源配对、多相册目录授权、4 MiB 分片续传及指定 Wi-Fi 定时同步。服务端新增受权限保护的缩略图、Dockerfile 和 Compose。

## 下载与连接

安装附件 `PhotoSync-0.12.0-debug.apk`。首次调试可通过 USB 执行 `adb reverse tcp:8080 tcp:8080`，应用填 `http://127.0.0.1:8080`，连接当前电脑的免登录原型；不需要在这台电脑重新创建真实账户。正式部署使用客户端账户及强制 TOTP，详见 [安卓文档](../ANDROID.md) 和 [部署文档](../DEPLOYMENT.md)。

## 当前限制

自动同步依赖系统后台调度、精确/后台定位及定位开关，不承诺连接 SSID 瞬间上传；无法读取 SSID 时暂停。原生生物认证只解锁有效会话，不跳过过期会话的 TOTP。暂不自动提取安卓厂商单文件 Motion Photo。NPU 人脸、115 加密上传、SnapRAID sync/scrub/fix 尚未实现。

GitHub access key 缺少 `workflow` scope，构建工作流作为 `docs/workflow-templates/` 模板交付，尚未启用；本地已构建 APK 不受影响。

此版本是开发预发布，保留原型和已有数据，不把硬件或端到端验收标记为完成。
