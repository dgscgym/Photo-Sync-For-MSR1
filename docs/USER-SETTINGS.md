# 用户菜单与图形化目录

0.9.0 导航：管理台侧栏只有服务概览与照片库。运行日志位于概览，级别为 INFO、DEBUG、WARN、ERROR；旧 warning 查询和记录仍兼容。相册同步、多盘保护、加密备份集中在用户菜单的设置页，SnapRAID 检查/已知晓操作也在多盘保护面板中。菜单字体固定为 14px，不继承页面品牌标题样式。

客户端与管理台右上角显示已登录用户名和头像首字。点击打开菜单，包含设置、退出登录；支持 Escape 和点击外部关闭。

- 客户端设置：/client/settings。
- 管理台设置：/admin/settings。
- 各自返回自己的主页，无客户端/管理台互跳链接。共享组件代码和 API 不代表页面跳转。
- 两侧均可浏览照片，管理台保留服务端功能。重复上传计数不再放在统计卡片中，实际去重和操作日志继续工作。

## 相册目录

原来的路径文本框改为“选择并确认目录”。弹窗先列出授权位置，可进入子目录、返回上级、逐页查看文件和文件夹，支持图片小预览与浏览器可播放视频的预览。确认选中目录后才登记并触发索引；可以重复添加多个目录，已登记目录显示为列表。

确认时附带目录身份/修改时间的 review_token。目录变化后旧 token 无效，需重看；目录登记不会复制、移动或删除原片。直接调用旧 API 的无 token 行为保留兼容，不应把 review_token 当作访问控制。

- GET /api/v1/library/browse：无 path 返回授权位置；path 和 offset 查询目录，每页 100 项。
- GET /api/v1/library/browse-preview?path=...：仅允许已授权范围内的受支持媒体，登录后读取；支持视频 Range。
- 所有显示的路径、文件名使用文本节点，浏览器不执行目录名里的 HTML。
- 不跟随符号链接，越界目录/预览被拒绝。不授权系统根目录或密钥目录。

## 本机相册

“选择相册文件夹”是浏览器所在设备的文件选择器，选中后再点上传。使用与主客户端相同的分片续传逻辑；当前不把浏览器相对路径当成服务端路径。

浏览器不能通过文本路径静默读取本机磁盘；本版未持久化目录句柄，不支持关闭页面后的后台同步。刷新后要重新选择相册，原分片可在文件未修改时续传。WebKitDirectory 支持程度取决于浏览器；Live Photo 的两资源关联仍需另行处理，文件夹导入不自动推断配对。

## SnapRAID

设置页内有独立 SnapRAID 面板，可查看状态、选择磁盘、预览和保存未同步方案；不跳进首次引导，不清除登录状态或媒体来源。运行中阵列的迁移限制仍与 0.7.0 一致。

当前仍使用同一个管理员账户，共用鉴权，不是多用户权限隔离。本机与 PVE 环境中实际磁盘和媒体范围需要部署时映射并授权；没有授权时显示空位置列表，不伪造磁盘或随意扩大访问范围。

已验证用户信息只对已登录会话返回、各设置页没有对方应用链接、目录内容查询不登记文件、确认后添加、过期确认拒绝、越界及符号链接拒绝。浏览器视觉自动化连接超时，尚未完成截图验收。
