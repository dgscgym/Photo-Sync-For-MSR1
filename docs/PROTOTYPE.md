# 0.11.0 · 免登录原型预览与媒体详情

## 直接看原型

```bash
.venv/bin/python -B -m server.app --prototype --port 8080 --data data/prototype-demo
```

管理台 /admin、客户端 /client 可直接打开，不需要创建账户、绑定验证器或登记设备。用户信息标为“原型预览”；认证相关操作明确提示未执行真实绑定，不返回假验证码或假注册成功。

- 仅允许 127.0.0.1 / localhost，不可绑定公网监听地址。
- 必须使用独立目录，拒绝打开已有真实账户的数据目录。
- 目录中写入 prototype.marker，正式模式拒绝直接使用它，避免混淆演示和真实数据。
- 正式模式仍强制账户权限与 2FA，没有将正式认证改成默认绕过。
- 不接入真实 SnapRAID 检查配置；生成方案仍不会自动同步、格式化或修复磁盘。

可选：只读引用旧预览中已经上传的素材，不搬动原片或导入账户：

```bash
.venv/bin/python -B -m server.app --prototype --port 8080 \
  --data data/prototype-demo --prototype-media-from data/preview-v0.5
```

只读取旧数据库的照片元数据，登记旧 originals 为只读引用来源。演示中新增上传和生成的预览保存在新的演示目录，真实账户和密钥保持不变。

## 本轮页面调整

- 管理台照片库增加照片/视频上传按钮，沿用分片、续传和 SHA256 去重；正式模式可直接使用管理员会话上传，无需另登录客户端。
- 客户端菜单移除运行日志，旧 /client/logs 地址返回客户端首页；服务端仍保留审计和上传日志。
- 两侧媒体详情新增存储位置、格式、分辨率、字节数、相机品牌/型号、镜头、光圈、快门、ISO、焦距、拍摄时间。视频可显示时长和编码。
- 图片使用 Pillow 读取真实尺寸与 EXIF，视频使用 ffprobe。缺失信息显示“未提供”，解析失败有明确提示，不填造样例参数。
- 正式客户端只显示逻辑存储位置，管理端可见实际路径；详情接口沿用用户媒体访问检查。
- EXIF 缺失、HEIC 或特定视频编码的解析能力受当前依赖支持限制，不保证能恢复已被转存软件删除的拍摄参数。

API：GET /api/v1/media-details/{sha256}?app=admin|client。存储内容和原始文件不会因查看详情而修改。

已验证免登录上传/详情、真实生成 JPEG 的尺寸和 EXIF、已有账户目录保护、非回环监听拒绝及正式模式不可直接打开演示数据。页面视觉仍待人工查看。
